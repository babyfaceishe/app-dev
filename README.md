## Favorite Movie

### **Training Day** (2001)
- **Genre**: Crime Thriller
- **Director**: Antoine Fuqua
- **Starring**: Denzel Washington, Ethan Hawke
- **What's special about the movie**: Denzel Washington's Oscar-winning performance as a corrupt detective is absolutely captivating. He always portrayed the character who was always a hero, but in this movie he was the opposite which is why I think this is one or probably the best movie he was in. He SLAYED this role and it never gets old. Denzel will always have that SWAG. The intense cat-and-mouse dynamic and moral complexity make this movie a masterpiece.
